# PrintGenie – Frontend Demo

This is a Vite + React frontend for the PrintGenie FYP.

## Included
- PrintGenie logo supplied for the project
- Redesigned first/splash page using the logo
- Login
- Signup
- Forgot Password
- OTP screen
- Role selection
- Success screen
- Responsive design
- Royal blue + gold branding

## Run in VS Code

1. Extract/open this folder in VS Code.
2. Open the terminal in the project folder.
3. Run:
   npm install
4. Then:
   npm run dev
5. Open the localhost URL shown by Vite.
